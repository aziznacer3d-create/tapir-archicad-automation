Comment lire cette page. « Absente » : Tapir ne lit ni n'écrit ce champ, donc Python n'y a pas accès. « Lecture seule » : Python peut le lire (GetDetailsOfElements…) mais pas le modifier. Le repérage se fait en lisant le code C++ de Tapir. Il est donc approximatif : un champ traité par un chemin détourné peut apparaître à tort comme absent. Ne sont pas comptés : les données hors des structures (polygones, profils, paramètres GDL, propriétés, classifications…) ni les champs réservés.
